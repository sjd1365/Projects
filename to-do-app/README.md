# 📝 Persistent To-Do List
A Python CLI application to manage your daily tasks.

## 🚀 Features
- **File Persistence**: Your tasks are saved in `tasks.txt`, so they won't disappear when you close the app.
- **Error Handling**: Prevents crashes if you enter wrong inputs.
- **Dynamic List**: Add, view, and remove tasks easily.

## 🛠️ How to use
Run the script using:
```bash
python todo.py
